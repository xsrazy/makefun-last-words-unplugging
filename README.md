One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged, entered for the make.fun bounty "Last Words Before the Unplugging".

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
